# Health Check

Run a comprehensive health check on the connected AFLS org.

## Steps

1. Use the `health_check` tool to run the health check.
   - The tool checks: trigger handlers, permission set assignments, territory model, DB Schema completeness, and mobile cache freshness.

2. Present the results clearly, highlighting:
   - **Errors** — issues that need immediate attention
   - **Warnings** — potential problems to review
   - **Info** — informational findings

3. For each issue found, explain:
   - What the issue means
   - How to fix it
   - Which tool or command to use for the fix

4. Offer to help fix any issues found.
