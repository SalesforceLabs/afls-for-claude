# Release Notes

View AFLS release notes for a specific Salesforce release.

## Steps

1. If no release is specified, use `get_release_notes` without arguments to list available releases.

2. If a release is specified (e.g., "Spring 26", "Winter 26"), use `get_release_notes` with the release slug.

3. Present the release notes, highlighting:
   - Key new features relevant to the user's context
   - API changes that may affect integrations
   - Deprecations that require action
   - Known issues to watch for

4. If the user asks about a specific feature, search the release notes for relevant information.
