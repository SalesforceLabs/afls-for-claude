# Life Sciences — Summer '26 (Release 262) Official Release Notes

Source: https://help.salesforce.com/s/articleView?id=release-notes.rn_lifesciences.htm&release=262&type=5

> AFLS is now Agentforce Life Sciences. You may see references to AFLS in our application and documentation.

## Overview

Enhance field agility and clinical efficiency with AI-powered tools and streamlined data management. Get started quickly by using a prebuilt Customer Engagement setup solution to install predefined objects and sample data. Field reps can now log visits by using voice commands and access intelligent, audio-based account briefings to prepare for engagements. Manage home health visits and maintain regulatory compliance through Microsoft Teams remote sessions, dynamic signature disclaimers, and automated communication cycles for Japanese market requirements.

## Streamline Event Planning and Execution

Drive greater operational efficiency with an intuitive event management framework that guides users through every stage of the event lifecycle. Use flexible workflow paths to surface role-specific actions that serve as built-in guardrails, keeping your events on track and compliant. Enforce budgetary constraints to monitor event expenses and manage event logistics with ease. On the day of the event, seamlessly complete event execution steps—from attendee sign-in to feedback collection—all from a single record page.

## Set Up Life Sciences Customer Engagement Using a Prebuilt Solution

Get started quickly with predefined objects, configurations, and sample data. The Agentforce Life Sciences Customer Engagement Solution turns on settings and installs core metadata, system configurations, FlexiPages, page layouts and business records required to try out the Life Sciences Customer Engagement core functionality. Using sample data, explore features for key personas, such as field users, account managers, and medical science liaisons. Or use your own business data to validate the solution against your specific requirements.

## Make Data Change Requests Accessible from the Record Page

Help field reps save time by enabling them to track and manage data change requests directly from the Related tab of the record page.

## Engagement Planning

Drive field agility and strategic planning by simplifying downtime entry workflows and unifying fragmented data for more cohesive engagement orchestration.

## Engagement Execution

Field reps can now log visits in the AFLS mobile app by using voice commands even while offline, and they can verify visit locations by using automated geolocation tagging. The mobile app and desktop site strengthen regulatory adherence by automating Massachusetts Controlled Substance Registration (MSCR) validation and dynamically displaying signature disclaimers based on a provider's language and country. Additionally, with optimized background synchronization, field teams have access to the latest data with improved performance. Enhance medical insight management with a custom web UI and hierarchical parent-child groupings. Simplify contact updates by allowing sales reps to add multiple communication channels directly from the consent management page.

## Institutional Doctor Accounts

Track engagements with healthcare professionals (HCPs) within the context of an affiliated healthcare organization (HCO). Automatically generate Institutional Doctor (Ins Doc) accounts from affiliation records to save time, reduce manual data entry, and ensure data accuracy. Use refined search to identify accurately Ins Doc accounts.

## Intelligent Content

Sales reps can build custom presentations and use interactive presentation tools across their devices to strengthen every interaction. Lead more meaningful sales conversations by accessing presentation materials, visit details, and related records in the same Service Console window. Install the Life Sciences Data Kit to access new email template data streams, mappings, and data model objects.

## Patient Engagement

Maintain care consistency by restricting task creation during work orders and streamline home visit scheduling with Home Health.

## Provider Engagement Compliance

Support Early Post-Marketing Phase Vigilance (EPPV) and Medical Information Delivery (MID) regulatory requirements by using Agentforce Life Sciences' Provider Engagement Compliance. To establish compliance during new product launches, configure periodic communication cycles. Sales reps can track compliance cycles to make sure that the regulatory requirements are met.

## Update LifeSciConfigRecord Files for New Profile Naming Format

LifeSciConfigRecord metadata files now use human-readable file names instead of org-specific profile IDs for profile-level and user-level configuration records in hierarchical categories.
