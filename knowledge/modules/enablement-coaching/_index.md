# Enablement Coaching

Enablement Coaching (new in Winter '27, release 264) lets a coach (typically a district manager or designated champion) run structured, scored field-coaching sessions against a weighted assessment rubric, with optional employee self-evaluation and formal acknowledgment. Each coaching record maps 1:1 to one employee (the data subject), self-evaluation and coach evaluation are two-way blind until the lock point, and the completed record is the permanent record of the coaching. Works on web and iPad (including offline). Built on Discovery Framework + OmniScript (assessment engine), Lightning Mobile Renderer (iPad screens) and Generic Workflow (lifecycle).
