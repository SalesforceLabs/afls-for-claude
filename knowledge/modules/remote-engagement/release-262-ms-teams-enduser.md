## Remote Engagement with Microsoft Teams - End User (Summer '26 GA)

Presenter: Eva Miguel, Product Manager, Agentforce Life Sciences

### Overview

Field users (sales reps, MSLs, key account managers) can seamlessly schedule and conduct remote engagement sessions with healthcare professionals using Microsoft Teams directly from the Agentforce Life Sciences app.

### Workflow

1. **Create remote visit** — Select HCP (e.g., Dr. Morita), set date/time, select Microsoft Teams as engagement channel
2. **Automatic invitation** — As soon as visit is saved, invitation is automatically sent to the HCP using compliant field email
3. **Start session** — From the visit engagement page, click "Start Remote Session" to launch Microsoft Teams using corporate account
4. **Present content** — Share screen in Teams, return to AFLS app to access content library or recommended presentations
5. **Personalization** — HCP's name embedded directly in content; presentation adapts to HCP profile
6. **Navigation & tools** — Move through pages, use drawings to highlight elements, use pointer for real-time focus, switch presentations without interrupting
7. **Switch back to Teams** — Return to Microsoft Teams to continue conversation
8. **Complete visit** — End call in Teams, return to visit record — presentation activity automatically captured (content, messages, products)
9. **Save/submit** — Ensures accurate reporting for compliance, performance tracking, and future engagement planning

### HCP Experience

- Receives branded email invitation (can accept/decline — response captured in Agentforce Life Sciences)
- Joins via Microsoft Teams link — no additional setup required

### Key Points

- Microsoft Teams powers the video interaction
- Agentforce Life Sciences manages visit context, content, and activity tracking
- Full clickstream metrics captured
- Content personalization works in real-time
- Compliant content delivery throughout
