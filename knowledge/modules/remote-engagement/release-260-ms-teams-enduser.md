# End User - Microsoft Teams Remote Engagement

Welcome everyone to this enablement recording series. My name is Eva Miguel. In this video, I'll show you the end user experience for running a remote engagement session using Microsoft Teams in AFLS.

We'll walk through authentication, creating a visit, launching the remote session, and presenting content while tracking engagement.

## Authentication

Before a user can plan or conduct remote sessions with Microsoft Teams, they need to authenticate once to create a secure connection between Salesforce and Microsoft Teams. From my profile I select "login into Microsoft Teams," which opens the external credential page.

I authenticate once, click "allow access," authenticate with my user, and confirm. The connection is configured. I could revoke access at any time if needed.

I could also do the same on web from my personal settings — go to external credentials, find the Microsoft Teams credentials delivered by AFLS, and select "allow access" to authenticate using my Microsoft Teams credential.

## Creating a Visit with MS Teams

I go to my account and select Dr. Aaron Morita. When I create a visit, I select the remote channel that has been configured to use Microsoft Teams. In this case, I have "MS Teams" here. I save.

At this time, a Microsoft Teams meeting is being created as well. I just need to synchronize to get the information down into the iPad.

From the rep's perspective, there is no manual meeting setup — everything is handled automatically from AFLS. Microsoft Teams app needs to be installed on iPad in order to launch the remote session.

## Launching the Remote Session

I open my visit and see the "start remote engagement" button at the top. I click on it and my meeting starts directly in Microsoft Teams. I click "join now."

This is the native Microsoft Teams app. I can enable my microphone, camera, and use other features available in meetings.

## HCP Experience

The HCP can join the session through their calendar. They will get invitations sent by Microsoft Teams (in the February '26 release). In the June release, this will be extended to remote invitations using approved field email. For now, HCPs join using their calendar or directly using the Microsoft Teams app.

## Content Sharing and Tracking

To start sharing content, the rep shares their screen (without audio if there are videos within the content). Then switch to the AFLS app to present content. The content is shared with the HCP through the screen sharing.

Microsoft Teams handles the video experience and AFLS handles the visit content and tracking. Everything that is presented will be tracked through the visit — page seen, product and message presented, time spent on each page. Everything will be tracked like any other visit.

Even though the remote session is conducted entirely in Microsoft Teams, content engagement and clickstream metrics are captured in AFLS for reporting and compliance.

## Completing the Visit

At the end, I hang up on Teams, switch back to my app, and complete my visit. Everything has been tracked and I click "save."
