# Field Events Management (Summer '26)

Presenter: Crystal Deshpande, Product Manager, Agentforce Life Sciences

## Overview

Field Events are part of the broader Agentforce Life Sciences events management module, allowing field teams to plan, execute, and track speaker or rep-led events while ensuring strict regulatory compliance and capturing a 360-degree view of HCP engagement.

## Event Lifecycle

### 1. Planning Phase (Draft Status)

**Create Event:**
- Navigate to Events Management tab in mobile app
- Select event type (drives downstream workflow) — e.g., Speaker Event
- Add header info: name, subtype, start/end date-time, owner

**Checklist:**
- Configurable required tasks needed before submission
- Visual indicator of completion status

**Define Topic & Product:**
- Select topic/subject for the event
- Product automatically added based on topic
- Topic drives downstream items (expert eligibility, email templates)

**Select Expert/Speaker:**
- Must be trained on selected topic
- Must have compliance training
- Only eligible experts are selectable

**Add Attendees (optional at this stage):**
- Can add potential HCP attendees
- Can also add later in workflow

**Add Organizers:**
- Colleagues helping plan/organize the event

**Logistics:**
- Location (venue name, type)
- Confirmation status (pending/confirmed)
- Meal type, special requests, room setup
- Reservation name and number

**Estimated Expenses:**
- Speaker fee
- Food and beverage estimates
- Other expense categories

**Submit for Approval**

### 2. Approved Phase

After manager approval:
- Confirm logistics (venue, speaker, attendees)
- Send email invitations (templates driven by event topic)
- Track RSVP responses (update status to accepted/declined)
- Confirm venue

### 3. Event Day Execution

**Attendee Sign-In:**
- Only attendees (not organizers/speakers) require sign-in
- Hand iPad to each attendee for signature
- Mark meal participation (yes/no)
- Status updates to "Attended"

**Capture Actual Expenses:**
- Record actual speaker fee
- Record actual food & beverage
- Allocate expenses to attendees:
  - Speaker fee → allocated to speaker (Dr. Morita)
  - F&B → allocated to attendees who ate

**Content Presentation:**
- Speaker can use iPad to present content during event

### 4. Close Event

Mark event as closed → captures final status.

## Key Features

- Event type drives entire workflow (configurable)
- Regulatory compliance built into every step
- Budget enforcement (estimated vs actual)
- 360-degree HCP engagement tracking
- Expense allocation per attendee
- Configurable checklists as guardrails
- Email invitation templates tied to event topic
- Sign-in with meal tracking
