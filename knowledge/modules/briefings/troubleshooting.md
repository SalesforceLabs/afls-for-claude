# Briefings Troubleshooting

## Common Issues

### Briefings icon not showing on iPad

**Most common cause:** The "Use Briefings" system permission (`PermissionsStoriesUser`) is not enabled.

Check:
1. User must have a permission set with `PermissionsStoriesUser = true` assigned
2. User's profile must be in an active `PrstCntntDefAssignment`
3. User must have read access to `PresentationContent` object

Verify: `SELECT Id, Label FROM PermissionSet WHERE PermissionsStoriesUser = true AND IsCustom = true`

All three conditions must be met for the icon to appear.

### "sObject type PresentationContent is not supported"

Two possible causes:

**1. Briefings toggle is OFF** — enable it:
- Setup → Life Sciences for Customer Engagement Setup → Configure Briefings → Toggle ON

When the toggle is OFF, all Briefings objects (`PresentationContent`, `PrstContentDefinition`, `PrstCntntDefAssignment`, `PrstCntntUsageSummary`) are inaccessible and Briefings flows don't appear.

**2. Admin lacks "Manage Briefings" permission** — even with the toggle ON and System Administrator profile, the admin cannot query `PresentationContent` without `PermissionsStoriesAdmin = true` on an assigned permission set.

**How to distinguish:** Run `SELECT Id FROM FlowDefinitionView WHERE Label LIKE '%Briefings%'`. If Briefings flows are returned, the toggle IS on — the issue is the missing **Manage Briefings** permission (`StoriesAdmin`). If no flows are returned, the toggle is truly OFF.

### No audio briefings generated

Check the pipeline:
1. Account Summarization flow ("Generate Provider Account Territory Summary") must be active
2. `PrvdAccountTerritorySummary` records must exist
3. Text generation flow (ApiName: `GenDailyBriefingsText`) must be active
4. The cloned scheduling flow must be active with Daily frequency
5. `PresentationContent` records should be created after the flow runs

### Audio plays in wrong language / sounds gibberish

Kokoro TTS uses **English pronunciation exclusively**. If the source data or app language is non-English, the generated audio will mispronounce non-English words.

English only in 262 GA.

### Briefings not updating with new visits

The playlist is **not dynamically updated** for same-day visit changes. It reflects the data generated by the scheduled flow run. Configure the flow to run early enough to capture all visit data.

### Timezone issues

If admin and field reps are in different time zones, the scheduled flow triggers based on the admin's local time zone. Advise reps to update calendars at least 2 days in advance.

### Duplicate PresentationContent records

Running the scheduled flow multiple times per day creates duplicate records. The mobile app uses the **latest created record** for each account.

## Diagnostic Checklist

Run `/afls:diagnose-briefings` for an automated check, or manually verify:

1. ✅ Briefings toggle ON (PresentationContent accessible)
2. ✅ 4 PSLs provisioned (Life Science Commercial, Health Cloud Starter, Agentforce for AFLS, Einstein Prompt Templates)
3. ✅ Managed package `lsc4ce` installed
4. ✅ Admin perm set with PermissionsStoriesAdmin = true + assigned
5. ✅ User perm set with PermissionsStoriesUser = true + assigned
6. ✅ Account Summarization flow active + records exist
7. ✅ PrstContentDefinition record exists + active
8. ✅ PrstCntntDefAssignment active for user's profile
9. ✅ Scheduling flow template exists (ApiName: SchdDlyBriefingsOfPrvdAcct) + clone active
10. ✅ 4 DB Schema configs active (PresentationContent, PrstCntntUsageSummary, PrstCntntDefAssignment, PrstContentDefinition)
11. ✅ Mobile metadata cache generated
