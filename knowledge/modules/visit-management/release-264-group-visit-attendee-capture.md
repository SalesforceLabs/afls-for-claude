# Simplified Attendee Data Capture in Group Visits - Winter '27 (264)

Platform: iPad and Web.

## What's New

- **Efficient navigation (default):** the Attendee Visit action now appears directly in the Attendees section of the parent visit. Attendee name buttons at the top of the Attendee Visit Engagement page save the current attendee visit and open the next one in one step. No additional setup beyond attendees being enabled.
- **Focused attendee data entry (optional):** the Attendee Visit Engagement page can show only the Samples, Direct to Practitioner, and Marketing Items sidebars. Detailed products and discussions are captured once on the parent visit and still carry over to all attendees on submit, as before.

## Admin Setup

1. Admin Console > Visit Administration > Visit Settings.
2. Enable **Capture only samples and marketing items per attendee**.
3. Run the metadata cache so the setting applies on the Visit Engagement page (mobile).

## End-User Flow

The rep clicks the next attendee's name to save and move to the next record. On each attendee page only the Samples and Marketing Items (and Direct to Practitioner) sidebars appear.
