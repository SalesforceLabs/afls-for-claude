## Intelligent Content on Web - Seamless Experience (Summer '26)

Presenter: Eva Miguel

### Overview

Intelligent content on web now delivers a seamless experience for users from preparation to interaction with full parity to mobile. Reps no longer need to switch devices or workflows — they can prepare, interact with content, and get ready for visits directly from web.

### Content Library on Web

- Access all presentations available for territory, organized by topics
- Find recently worked-on content
- Mark favorites (shared across web and mobile)
- Create custom presentations

### Custom Presentations

For short meetings, reps can create tailored custom presentations:
- Select relevant slides from multiple presentations
- Combine different pages from different presentations
- Assign topics
- Save for reuse

### Contextualized Content from Visit

When launching content library from within a visit record:
- Content is automatically filtered based on HCP profile, targeting, and visit rules
- Recommended presentations surface based on visit context
- Save presentations directly to the visit

### Preview Mode

- Preview mode for preparation (no clickstream data captured)
- Consistent experience with mobile: page thumbnails, navigation controls, player menu, interactive tools

### Dynamic Personalization

- HCP name appears automatically in content (pulled from account data)
- Content adapts based on attributes: specialty, therapeutic interest
  - Cardiologist → advanced cardiology-specific data
  - General practitioner → high-level overview
- Content adapts to region/language (e.g., US/Mexico, English/Spanish)
- One single presentation but experience adapts in real time — no need for multiple versions

### Interactive Tools on Web

- Drawing mode to highlight important data
- Laser pointer for key areas
- Email icon embedded in content for direct sharing
- Animations, videos, and surveys supported (same as mobile)

### Key Capabilities (same as mobile)

- Capture feedback by writing content notes
- Send presentations by email (compliant templates, right content attached)
- Switch or add content on the fly
- Smart content search (goes beyond metadata — searches inside content)

### Important Note

Web now delivers the same intelligent content experience as mobile with:
- No additional setup required
- Full flexibility to prepare or present from either device
- Favorites synced across devices
