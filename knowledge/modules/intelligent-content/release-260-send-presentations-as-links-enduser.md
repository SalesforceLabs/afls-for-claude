# End User - Send Presentations as Links

Welcome everyone to this series of enablement recordings. My name is Eva Miguel and in this video I'll guide you through the end user experience for sending presentations as links. This capability is available on both iPad and web.

## iPad Experience

Let's start on the iPad. I open my application and navigate to my content library on the top tab "intelligent content". We can see the list of presentations here.

**Sending a single presentation:** If I want to send a single presentation, I tap on the email icon and then select my account.

**Sending multiple presentations:** To add multiple presentations to a single email, I select them one by one. For example, Hypertension 2026 — I click here and select it. As soon as I select it, you see "selected" and also a new "email" button. I also add Immunexis. I can see there are two selected.

**Compliance controls:** If a presentation is not allowed to be sent, you'll notice that neither the mail icon nor the plus icon is available. There will also be an indicator showing this is not allowed to be sent. This ensures compliance and prevents unauthorized sharing.

**Selecting recipients:** I click on email. Next, I select my account. I can select one single account or multiple accounts. If an account is restricted for any of the products linked to the selected presentations, it will appear as disabled — AFLS respects the compliance rules. I select Aaron Morita and click next.

**Email template selection:** From here the system follows the standard email flow. We can select only those email templates that have been configured with placeholders to embed the link inside. I select a template, click next.

**Reviewing the email:** I can still add attachments. I see the placeholder where the presentation links will be placed. I can edit it, remove presentations, or change the order. Then click save, click next.

**Final review and send:** I see the final email with the two links to those presentations. I click next. Before sending, if there are any consent rules in place they will be fully respected. Once everything looks good, I tap on send and the mail is sent.

**Sending from the player:** There is another way — directly from the player. I open a presentation, present it, then tap the email icon. If the account is already added into the visit or player, it will be automatically added. All presentations that have been played will be stored in memory and links will be generated for those presented presentations.

**Important:** The link generation happens at the end — when clicking "send" is when the link will be generated per recipient and per presentation.

## HCP Experience

The HCP will receive an email with links to the presentations. When they tap on a link, it automatically opens the player and they can navigate through the presentation. They can play animations if available. Every interaction is captured — including page views, time spent on each page, and navigation order — giving full visibility into engagement while maintaining a seamless experience for the recipient.

## Web Experience

On web the experience is mostly the same. Navigate to intelligent content, select presentations, click on email, select the doctor, select the email template. The placeholder shows where the content builders have added space for the presentation links. Click next, same consent rules apply, then send. The presentation will be sent to the selected recipients.
