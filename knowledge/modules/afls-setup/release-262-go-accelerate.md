# AFLS Easy Setup - Go Accelerate (Summer '26)

Presenter: Manoj Mohapatra, Product Manager, AFLS

## Overview

Leverages the Go Accelerate framework to set up Agentforce for Life Sciences with predefined objects, configurations, and sample data. Available through Salesforce Go in Setup.

## Access

Setup → Salesforce Go → Home tab → **Agentforce for Life Sciences** (also available in initial setup tile)

## Installation Options

### Standard Installation (One-Click)
Sets up everything with a single click:
- Required metadata
- Object configuration
- Page layouts
- FlexiPages
- Sample data

### Custom Installation (Cherry-Pick)
Allows selecting specific components:

**Core Configuration:**
- Profiles
- Metadata
- Object configuration

**Enhanced Experience:**
- FlexiPages
- Page layouts
- Sample data

## What Gets Installed

### Permission Sets
Required permission sets for AFLS personas

### Profiles
Profile configurations for field users

### Metadata
Core metadata records and custom field values

### Page Layouts & FlexiPages
Pre-configured layouts for AFLS objects

### Sample Data
- Account data
- Visit Management data
- Key Account Manager data
- Medical Inquiries data

## Important Notes

- Standard installation cannot be undone (warning shown before install)
- Installation takes a few minutes to complete
- Expands to show all items being installed during progress
- Designed for quick org setup and evaluation
